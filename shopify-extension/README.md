# ForgeLinc Shopify extension starter

This is source for the Shopify storefront integration, not an already installed or approved app.
The live private ForgeLinc studio is a separate working preview; its ChatGPT authentication is not Shopify OAuth and its URL must not be used as a finished embedded Shopify App URL.

## Developer setup
1. Use Shopify CLI to scaffold an app with a theme app extension, linked to the ForgeLinc Team Shop app registered in the merchant's Dev Dashboard. Preserve the app and extension identifiers generated by Shopify CLI.
2. Copy blocks/team-selector.liquid and assets/team-shop.js and team-shop.css from this starter into that generated theme extension. The included TOML is illustrative; preserve the generated extension UID.
3. Test with Shopify CLI app dev on a development store. Run Shopify app build and theme checks.
4. Deploy with Shopify CLI app deploy. Use custom distribution for the merchant's store and its install link.
5. In the theme editor, add the ForgeLinc team shop app block. Choose the published products created through Printify (one Printify-linked product for each team/theme/front-logo combination).
6. Add these single-line text product metafields in Shopify and set them on each published design:
   - `custom.team_name`: the same team name for all of that team's designs.
   - `custom.jersey_theme`: `Light` or `Dark`.
   - `custom.front_logo`: a distinct logo name, such as `Team crest` or `Alternate eagle`.
   Select all those products in the theme block. The selector groups them by team, then theme, then front logo. Missing theme/logo metadata defaults to Light / Team crest; missing team metadata uses the product title. Each combination must have one mapped product; use its real size variants.
7. Verify every team and variant, inventory/sold-out states, prices/currency, cart, checkout and fulfillment with a sample order before launch.

## How fulfillment stays correct
The product picker switches the entire product object, including real Shopify variant IDs. Cart additions use that selected product's available variant. A line-item Team label is descriptive, not a replacement for variant mapping. Existing Printify product links handle fulfillment. Do not create a second API fulfillment path while native Printify order import is active.

## Limitations and next phase
This starter targets one jersey family and up to 50 selected team products. It is not a general product personalizer or full multi-merchant SaaS app. It does not automatically publish the private studio drafts. That requires authenticated Shopify Admin API and Printify API integration, durable mapping, retries and order tests. Public App Store distribution needs a production merchant-authenticated app and Shopify review.

## Custom uploads
The private ForgeLinc studio preview supports uploaded front logos and saves each personalized configuration as a separate design. It can generate that exact five-panel Printify draft for review. The Shopify theme extension intentionally offers only published, mapped products. A customer upload must not be attached as a property to a generic Printify variant and then sent to automatic fulfillment: that variant still prints its original artwork. Public uploads need a merchant-authorized upload service, an immutable design/order mapping, and a fulfillment review/hold flow before activation. None of those public endpoints or order automation are enabled by this starter.
